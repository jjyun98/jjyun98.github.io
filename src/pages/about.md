통계학 전공, 금융경제학 부전공 배경을 바탕으로 데이터 분석과 데이터 파이프라인을 다룹니다.

Python, R, SQL을 중심으로 데이터 전처리, 지표 설계, 통계적 검증, 모델링을 다룹니다. 유저 행동 분석, 리텐션/퍼널 분석, A/B 테스트 같은 제품 분석 주제와 함께 주식, 금융, 개인 건강, 자전거 운동 데이터처럼 직접 관심 있는 데이터를 분석합니다.

데이터 수집과 파이프라인 구축에도 관심이 있습니다. API와 크롤링으로 데이터를 모으고, AWS와 Airflow를 활용해 적재, 변환, 자동화 흐름을 구성하는 과정을 정리합니다.

통계 분석은 전공 서적을 바탕으로 개념과 직관을 풀어서 설명하는 방향을 지향합니다. 시계열, 베이지안 분석, 텍스트 분석, 생존분석, 의학통계처럼 프로젝트에서 만난 주제도 함께 다룹니다.

필요한 경우 머신러닝과 딥러닝도 활용합니다. 모델 성능 평가, 사전학습 모델 파인튜닝, XAI 기반 해석, CNN 이미지 분류 같은 내용을 분석 문제와 연결해 기록합니다.
