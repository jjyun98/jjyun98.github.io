### 1. dm-overview · B형 · ISLR 1~2장 + 강의 `sheet_1.jpg`

**목표 목차**

1. 데이터 마이닝이란: 정의, KDD, CRISP-DM, 강의의 작업 분류(분류, 추정, 예측, 연관, 군집)
2. 통계적 학습의 틀: $Y=f(X)+\epsilon$, 예측과 추론, 줄일 수 있는 오차와 줄일 수 없는 오차
3. f를 추정하는 방법: 모수적, 비모수적, 유연성과 해석 가능성
4. 문제의 분류: 지도, 비지도, 준지도, 회귀, 분류
5. 모형 평가: MSE, 훈련 오차와 테스트 오차, 편향-분산
6. 분류의 평가: 오류율, 베이즈 분류기, KNN
7. 비교: 시리즈 전체 방법 표
8. 시리즈 구성: 18편과 ISLR 장 대응

**핵심 식**

- $E(Y-\hat Y)^2=[f(X)-\hat f(X)]^2+\mathrm{Var}(\epsilon)$
- $\mathrm{MSE}=\frac1n\sum(y_i-\hat f(x_i))^2$
- $E[y_0-\hat f(x_0)]^2=\mathrm{Var}(\hat f(x_0))+[\mathrm{Bias}(\hat f(x_0))]^2+\mathrm{Var}(\epsilon)$
- 베이즈 오류율 $1-E[\max_j P(Y=j\mid X)]$
- KNN $P(Y=j\mid X=x_0)=\frac1K\sum_{i\in\mathcal N_0}I(y_i=j)$

**비교 축:** 방법 / 문제 / 모수적 여부 / 유연성 / 해석 가능성 / 주요 조율 모수 / 해당 글

**예시:** 기존 시뮬레이션 유지. KNN의 K=1, 10, 100 결정경계 그림을 추가한다.

**그림(SVG):** 유연성-해석 가능성 배치도, CRISP-DM 흐름.

**고칠 것:** 시리즈 구성 표의 "10, 11장을 다루지 않는다" 문장을 지우고 표를 18편으로 바꾼다.

### 2. dm-linear-regression · B형 · ISLR 3장

현재 3,508자, 잔차 진단 24줄로 얇다. 약 2배로 늘어난다.

**목표 목차**

1. 단순선형회귀: 최소제곱, 계수의 정확도, 모형의 정확도
2. 다중선형회귀: 추정, 해석(단순회귀 계수와 달라지는 이유)
3. 네 가지 질문: 관계 유무(전체 F, 부분 F), 변수 선택, 적합, 예측
4. 질적 변수: 2수준, 3수준 이상 코딩
5. 선형모형 확장: 상호작용과 계층 원칙, 다항 회귀
6. 여섯 가지 문제: 각 문제의 정의 → 진단 → 처방
7. 비교: 신뢰구간과 예측구간, 선형회귀와 KNN 회귀, 여섯 문제 진단표
8. 예시와 사용: Marketing Plan(Advertising), Credit 질적 변수, Boston 진단, Auto 다항, Carseats

**핵심 식**

- $\hat\beta_1=\frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2}$, $\hat\beta_0=\bar y-\hat\beta_1\bar x$
- $\mathrm{SE}(\hat\beta_0)^2$, $\mathrm{SE}(\hat\beta_1)^2$, $t$, $\mathrm{RSE}=\sqrt{\mathrm{RSS}/(n-p-1)}$, $R^2=1-\mathrm{RSS}/\mathrm{TSS}$
- $F=\frac{(\mathrm{TSS}-\mathrm{RSS})/p}{\mathrm{RSS}/(n-p-1)}$, $F=\frac{(\mathrm{RSS}_0-\mathrm{RSS})/q}{\mathrm{RSS}/(n-p-1)}$
- $h_i=\frac1n+\frac{(x_i-\bar x)^2}{\sum(x_{i'}-\bar x)^2}$
- $\mathrm{VIF}(\hat\beta_j)=\frac{1}{1-R^2_{X_j\mid X_{-j}}}$
- $\hat f(x_0)=\frac1K\sum_{x_i\in\mathcal N_0}y_i$

**비교 표**

| 문제 | 증상 | 진단 | 처방 |
|---|---|---|---|
| 비선형 | 잔차의 곡선 패턴 | 잔차-적합값 | 변수 변환, 다항 |
| 오차항 상관 | SE 과소, 구간 과소 | 잔차 시계열 그림, DW | 설계 수정, 시계열 모형 |
| 이분산 | 깔때기 | 잔차-적합값 | 로그 변환, 가중최소제곱 |
| 이상점 | 큰 잔차 | 스튜던트화 잔차 > 3 | 입력 확인, 제거 신중 |
| 지렛값 | 극단 x | $h_i$ | 영향 확인 |

### 3. dm-logistic-regression · B형 · ISLR 4.1~4.3, 4.6

**목표 목차**

1. 왜 선형회귀가 아닌가
2. 로지스틱 모형: 식, 오즈와 로그오즈, 계수 해석
3. 최대가능도: 가능도 식, Wald z
4. 예측과 다중 로지스틱, 교란
5. 다범주: 기준범주 코딩, 소프트맥스 코딩
6. 기준값과 혼동행렬 (ROC 상세는 4번 글)
7. GLM: Bikeshare에서 선형회귀의 한계 → 포아송 회귀 → 일반형
8. 비교: 선형확률모형, 로지스틱, 포아송, 일반 GLM 표
9. 예시와 사용: Default, Smarket 시작, Bikeshare

**핵심 식**

- $p(X)=\frac{e^{\beta_0+\beta_1X}}{1+e^{\beta_0+\beta_1X}}$, $\log\frac{p}{1-p}=\beta_0+\beta_1X$
- $\ell(\beta)=\prod_{y_i=1}p(x_i)\prod_{y_{i'}=0}(1-p(x_{i'}))$
- 기준범주: $\log\frac{P(Y=k)}{P(Y=K)}=\beta_{k0}+\sum\beta_{kj}x_j$
- 소프트맥스: $P(Y=k\mid x)=\frac{e^{\beta_{k0}+\sum\beta_{kj}x_j}}{\sum_{l}e^{\beta_{l0}+\sum\beta_{lj}x_j}}$
- 포아송: $\log\lambda(X)=\beta_0+\sum\beta_jX_j$, $\mathrm{Var}(Y)=E(Y)$
- GLM: $\eta[E(Y\mid X)]=\beta_0+\sum\beta_jX_j$

**비교 축:** 반응 분포 / 연결 함수 / 평균-분산 관계 / 평균 범위 / 해석

**유지:** student 부호 변화(교란) 설명.

**고칠 것:** "선형확률모형 비교"와 "GLM으로 본 회귀모형들"의 중복을 비교 절 하나로 합친다.

### 4. dm-classification · A형 · ISLR 4.4~4.5, 4.7

**목표 목차**

1. 개념
   - 생성 모형의 틀: 베이즈 정리로 분류
   - LDA p=1: 판별함수와 경계 유도
   - LDA p>1: 다변량 정규, 판별함수, 혼동행렬, 기준값, ROC, AUC
   - QDA: 판별함수, LDA와의 편향-분산
   - 나이브 베이즈: 독립 가정, 밀도 추정 3가지
   - KNN: 비모수 방법
2. 비교
   - **해석적 비교:** 로그오즈 형태 비교(ISLR 4.5.1)
   - 비교표 (기존 표 유지)
   - **경험적 비교:** 6개 시나리오 상자그림(ISLR 4.5.2)
   - 선택 기준
3. 예시와 사용
   - Default: LDA, 기준값 조정, ROC
   - Smarket: 로지스틱, LDA, QDA, NB, KNN 같은 분할 비교 (ISLR 4.7)
   - Caravan: KNN과 표준화, 양성 비율이 낮을 때의 해석
   - iris: 판별축 (기존 유지)

**핵심 식**

- $P(Y=k\mid X=x)=\frac{\pi_kf_k(x)}{\sum_l\pi_lf_l(x)}$
- $\delta_k(x)=x\frac{\mu_k}{\sigma^2}-\frac{\mu_k^2}{2\sigma^2}+\log\pi_k$, 경계 $x=\frac{\mu_1+\mu_2}{2}$
- $\hat\mu_k$, $\hat\sigma^2$, $\hat\pi_k$
- $\delta_k(x)=x^T\Sigma^{-1}\mu_k-\frac12\mu_k^T\Sigma^{-1}\mu_k+\log\pi_k$
- QDA $\delta_k(x)=-\frac12(x-\mu_k)^T\Sigma_k^{-1}(x-\mu_k)-\frac12\log|\Sigma_k|+\log\pi_k$
- NB $f_k(x)=\prod_jf_{kj}(x_j)$
- 로그오즈 비교 ($K$ 기준):
  - LDA $a_k+\sum_jb_{kj}x_j$
  - QDA $a_k+\sum_jb_{kj}x_j+\sum_j\sum_lc_{kjl}x_jx_l$
  - NB $a_k+\sum_jg_{kj}(x_j)$

**비교 절에서 반드시 말할 관계 (ISLR 4.5.1의 결론)**

- LDA는 $c_{kjl}=0$인 QDA의 특수한 경우다.
- 선형 경계 분류기는 $g_{kj}(x_j)=b_{kj}x_j$인 NB의 특수한 경우다.
- 범주 공통 분산을 쓰는 정규 NB는 $\Sigma$를 대각으로 제한한 LDA다.
- QDA와 NB는 서로의 특수한 경우가 아니다.
- 로지스틱과 LDA는 형태가 같고 추정 방식이 다르다.
- KNN은 비모수이며, 경계가 복잡하고 $n$이 $p$보다 클 때 유리하다.

**시나리오:** ISLR 4.5.2의 시나리오 1~6 설정을 PDF에서 확인해 그대로 구현한다. 테스트 오류율 상자그림을 그리고, 평균의 몬테카를로 표준오차를 표로 적는다. 현재 8절 모의실험의 유효한 부분은 합친다.

### 5. dm-resampling · A형 · ISLR 5장 · **파일럿 글**

2. 비교: 검증셋/LOOCV/k-겹 표 **한 번**, k에 따른 편향-분산, CV와 부트스트랩의 목적 차이
3. 예시와 사용

**핵심 식**

- $\alpha=\frac{\sigma_Y^2-\sigma_{XY}}{\sigma_X^2+\sigma_Y^2-2\sigma_{XY}}$

- `:217` 차이의 몬테카를로 표준오차(약 0.003)를 함께 적는다.

### 6. dm-regularization · A형 · ISLR 6.1~6.2

**목표 목차**

1. 개념
   - 최소제곱의 한계
   - 부분집합 선택: 최량(알고리즘 6.1), 전진(6.2), 후진(6.3), 혼합
   - 모형 선택 기준: Cp, AIC, BIC, 수정 R², 검증과 CV, 1-표준오차 규칙
   - Ridge: 목적함수, 표준화, 편향-분산
   - Lasso: 목적함수, 제약 형태, 계수가 0이 되는 이유
   - 특수한 경우: $X=I$에서의 해
   - 베이즈 해석
   - $\lambda$ 선택
   - Elastic Net (ISLR 밖 보충, 표시)
2. 비교: 부분집합/Ridge/Lasso/Elastic Net, 희소한 참 모형과 조밀한 참 모형 모의실험
3. 예시와 사용: Hitters로 기준별 선택, 계수 경로, 테스트 오차

**핵심 식**

- $C_p=\frac1n(\mathrm{RSS}+2d\hat\sigma^2)$, $\mathrm{AIC}=\frac{1}{n}(\mathrm{RSS}+2d\hat\sigma^2)$ (최소제곱 정규 오차에서 상수배 제외), $\mathrm{BIC}=\frac1n(\mathrm{RSS}+\log(n)d\hat\sigma^2)$, 수정 $R^2$
- Ridge: $\sum(y_i-\beta_0-\sum\beta_jx_{ij})^2+\lambda\sum\beta_j^2$, 표준화 $\tilde x_{ij}=\frac{x_{ij}}{\sqrt{\frac1n\sum(x_{ij}-\bar x_j)^2}}$
- Lasso: $\mathrm{RSS}+\lambda\sum|\beta_j|$
- 제약 형태: $\min\mathrm{RSS}$ s.t. $\sum\beta_j^2\le s$, $\sum|\beta_j|\le s$, $\sum I(\beta_j\ne0)\le s$
- $X=I$: $\hat\beta_j^R=\frac{y_j}{1+\lambda}$, $\hat\beta_j^L=\mathrm{sign}(y_j)(|y_j|-\lambda/2)_+$
- 베이즈: 정규 사전분포의 사후 최빈값 = Ridge, 라플라스 사전분포의 사후 최빈값 = Lasso

**비교 축:** 벌점 / 변수 선택 여부 / 공선성 대응 / 해의 형태 / 적합한 상황 / 주의점

**고칠 것**

- `:220` `Walks` 비율 0.54는 "절반 이하"가 아니다. `HmRun`은 누적 변수가 아니다. 출력과 변수 정의를 확인해 고친다.
- `:285`, `:355`, `:360` 한 분할, 소수 반복의 차이를 일반화한 표현을 낮춘다. 몬테카를로 표준오차를 넣는다.
- PCR, PLS 내용(5, 6절, `:287~309`)은 7번 글로 옮긴다.

**유지:** 계수가 0이 되는 이유 설명, 희소/조밀 모의실험.

### 7. dm-pcr-pls-high-dim (신규) · A형 · ISLR 6.3~6.4

**목표 목차**

1. 개념
   - 차원축소 회귀의 틀: $Z_m$, 선형 제약
   - PCA 3문장 요약 (`/posts/dm-pca` 링크)
   - PCR: 절차, 가정, 표준화, 성분 수 선택
   - PLS: 계산 단계, PCR과의 차이
   - 고차원 자료: 무엇이 고차원인가
   - 고차원에서 잘못되는 것: 훈련 $R^2$가 1로
   - 고차원 회귀: 정규화, 차원의 저주
   - 고차원 결과의 해석: 다중공선성의 극단, 훈련 지표를 보고하지 않기
2. 비교: PCR/PLS/Ridge/Lasso 표, PCR이 Ridge와 비슷한 이유, 비지도와 지도의 차이
3. 예시와 사용
   - Hitters: PCR, PLS 성분 수와 테스트 오차 (6번 글에서 이동)
   - 모의실험: 무관한 변수를 늘릴 때 훈련 $R^2$, 훈련 MSE, 테스트 MSE
   - 모의실험: $p=20, 50, 2000$에서 Lasso의 테스트 MSE와 $\lambda$
   - Khan: $p>n$ 자료에 Lasso

**핵심 식**

- $Z_m=\sum_j\phi_{jm}X_j$, $y_i=\theta_0+\sum_m\theta_mz_{im}+\epsilon_i$
- $\beta_j=\sum_m\theta_m\phi_{jm}$
- PLS 첫 방향: $\phi_{j1}$ = $Y$를 $X_j$에 단순회귀한 계수, 이후 잔차화 반복
- $n\le p+1$이면 $\mathrm{RSS}=0$, $\hat\sigma^2=0$이어서 Cp, AIC, BIC를 그대로 쓸 수 없다.

**그림(SVG):** PC1 방향 투영과 PLS 방향의 차이.

**주의:** 고차원에서 찾은 변수는 예측에 쓸 수 있는 여러 조합 중 하나일 뿐, 유일한 원인이 아니다. 훈련 오차 대신 독립 검증 자료의 오차를 보고한다.

### 8. dm-nonlinear · A형 · ISLR 7장

**목표 목차**

1. 개념

   - 국소 회귀: 알고리즘, 스팬, 변동계수 모형
   - GAM: 회귀, 역적합, 분류
2. 비교: 유연성 조절 방법, 전역과 국소, 경계 거동, 해석 (기존 표 + 선택 기준)
3. 예시와 사용: Wage
   - 차수 선택: ANOVA 중첩 비교와 CV
   - `I(wage > 250)` 로지스틱 다항, 계단

   - GAM 회귀와 로지스틱 GAM

**핵심 식**

- $\widehat{\mathrm{Var}}\hat f(x_0)=\ell_0^T\hat C\ell_0$
- $y_i=\beta_0+\sum\beta_jb_j(x_i)+\epsilon_i$
- $h(x,\xi)=(x-\xi)_+^3$, 3차 스플라인의 자유도 $K+4$, 자연 스플라인은 경계에서 선형
- $\sum(y_i-g(x_i))^2+\lambda\int g''(t)^2dt$
- $\hat g_\lambda=S_\lambda y$, $df_\lambda=\sum\{S_\lambda\}_{ii}$, $\mathrm{RSS}_{cv}(\lambda)=\sum\left(\frac{y_i-\hat g_\lambda(x_i)}{1-\{S_\lambda\}_{ii}}\right)^2$
- 국소 회귀: $\sum K_{i0}(y_i-\beta_0-\beta_1x_i)^2$
- GAM: $y_i=\beta_0+\sum f_j(x_{ij})+\epsilon_i$, $\log\frac{p}{1-p}=\beta_0+\sum f_j(X_j)$

**패키지:** `gam` 설치를 시도한다. 실패하면 `mgcv`를 쓰고 ISLR과 패키지가 다름을 적는다.

**유지:** 경계 거동 비교.

### 10. dm-ensemble · A형 · ISLR 8.2

**목표 목차**

1. 개념: 부트스트랩 복습, 배깅, OOB, 변수 중요도, 랜덤포레스트, 부스팅(알고리즘 8.2), **BART(알고리즘 8.3)**
2. 비교: 네 방법 표 (나무 구조, 표본, 후보 변수, 결합 방식, 과적합, 조율 모수)
3. 예시: Carseats(기존), Boston에서 네 방법 동일 분할 비교(ISLR 8.3), 나무 수에 따른 오차, 중요도

**핵심 식**

- $\hat f_{bag}(x)=\frac1B\sum\hat f^{*b}(x)$
- 상관된 평균의 분산 $\rho\sigma^2+\frac{1-\rho}{B}\sigma^2$
- $m\approx\sqrt p$
- 부스팅: $\hat f(x)\leftarrow\hat f(x)+\lambda\hat f^b(x)$, $r_i\leftarrow r_i-\lambda\hat f^b(x_i)$, $\hat f(x)=\sum\lambda\hat f^b(x)$
- BART: $\hat f^b(x)=\sum_{k=1}^K\hat f_k^b(x)$, $\hat f(x)=\frac{1}{B-L}\sum_{b=L+1}^B\hat f^b(x)$, 부분 잔차 $r_i=y_i-\sum_{k'<k}\hat f_{k'}^b(x_i)-\sum_{k'>k}\hat f_{k'}^{b-1}(x_i)$

**고칠 것**

- `:22`, `:109`의 "상호 독립", "병렬, 독립"이 `:72`의 "독립이 아니다"와 충돌한다. 부트스트랩 표본과 나무가 **조건부로 독립적으로 생성되지만 공통 자료 때문에 상관된다**고 통일한다.
- 부스팅 표의 "전체 자료"와 `gbm` 기본 `bag.fraction=0.5`가 다르다. 어떤 알고리즘인지 구분하고 코드 인자를 명시한다.
- `:213` SD 0.026과 0.023 비교는 이항 잡음 약 0.028, 표준오차 약 0.003을 고려하면 "안정적"이라 단정할 수 없다. 표현을 낮추고 몬테카를로 표준오차를 적는다.

**패키지:** `BART` 설치를 시도한다.

**유지:** 지니 중요도의 편향 설명.

### 11. dm-svm · A형 · ISLR 9장

**목표 목차**

1. 개념: 초평면, 분리 초평면 분류, 최대 마진, 서포트 벡터 분류기(C), 커널, SVM, 일대일, 일대다, 손실 관점
2. 비교: 최대 마진/SVC/SVM, 힌지와 로지스틱 손실, 선형 커널과 로지스틱, 선택 기준
3. 예시: 모의 자료 비용·커널 모수, 경계가 비선형인 자료, OJ, **Heart ROC**, **Khan**

**핵심 식**

- 최대 마진: $\max M$ s.t. $\sum\beta_j^2=1$, $y_i(\beta_0+\sum\beta_jx_{ij})\ge M$
- SVC: 위 + $y_i(\cdot)\ge M(1-\epsilon_i)$, $\epsilon_i\ge0$, $\sum\epsilon_i\le C$
- $f(x)=\beta_0+\sum_{i\in\mathcal S}\alpha_i\langle x,x_i\rangle$
- $K(x_i,x_{i'})=\sum x_{ij}x_{i'j}$, $(1+\sum x_{ij}x_{i'j})^d$, $\exp(-\gamma\sum(x_{ij}-x_{i'j})^2)$
- $\min\sum\max[0,1-y_if(x_i)]+\lambda\sum\beta_j^2$

**주의로 넣을 것:** ISLR의 $C$는 위반 예산이어서 커질수록 마진이 넓다. `e1071::svm`의 `cost`는 위반 비용이어서 커질수록 마진이 좁다.

### 12. dm-neural-network (신규) · B형 · ISLR 10.1, 10.2, 10.7, 10.8

소주제마다 개념 뒤에 예시를 붙인다. 비교는 글 끝에 한 번만 둔다. 앞 글(`dm-svm`)에서 힌지 손실과 마진, 뒤 글(`dm-deep-learning`)에서 CNN과 RNN으로 이어진다.

**목표 목차**

1. **단층 신경망 (10.1)**
   - 구조: 입력층, 은닉층, 출력층. 은닉 활성 $A_k$는 입력의 선형결합을 비선형으로 변환한 새 특성이고, 출력은 그 $K$개 활성에 대한 선형회귀다(7장 기저함수와 같은 발상).
   - 활성화 함수: 시그모이드(로지스틱 회귀와 같은 함수), ReLU. ReLU는 0에서 꺾이지만 $w_{k0}$가 꺾이는 위치를 옮긴다.
   - 비선형이 필수인 이유: 활성화가 없으면 $f(X)$는 $X$의 선형모형으로 붕괴한다.
   - 적합: 양적 반응이면 제곱오차 손실.
   - **예시: $g(z)=z^2$ 손계산** (ISLR 10.6~10.8). $K=2$, $\beta=(0,\tfrac14,-\tfrac14)$, $w_1=(0,1,1)$, $w_2=(0,1,-1)$이면 $f(X)=X_1X_2$. 두 비선형 변환의 합이 상호작용을 만든다. 실제로는 $z^2$이 2차 다항식만 만들므로 시그모이드나 ReLU를 쓴다는 점도 적는다.
2. **다층 신경망 (10.2)**
   - 두 은닉층의 활성화 재귀식, 층별 가중치 행렬 $W_1, W_2$와 출력 가중치 $B$.
   - 출력이 여러 개인 경우: 다중 과제 학습. MNIST의 10개 출력은 하나의 질적 반응을 원-핫으로 둔 것이다.
   - 소프트맥스와 교차 엔트로피. 양적 반응이면 제곱오차를 쓴다.
   - 용어 주의: 신경망의 "weights, bias"는 계수와 절편이다. 편향-분산의 bias와 다르다.
   - **예시: MNIST 모수 수 세기와 Table 10.1.**
     - $785\times256=200{,}960$, $257\times128=32{,}896$, $129\times10=1{,}290$, 합 $235{,}146$.
     - 다항 로지스틱은 $785\times9=7{,}065$이므로 약 33배.
     - 훈련 자료 60,000건의 약 4배에 가까운 모수여서 규제가 필수다.
     - Table 10.1(ISLR 인용): 능선 신경망 2.3%, 드롭아웃 신경망 1.8%, 다항 로지스틱 7.2%, LDA 12.7%.
3. **적합 (10.7, 10.7.1, 10.7.2)**
   - 문제의 성격: 은닉 단위의 대칭과 중첩 구조 때문에 목적함수가 **비볼록**이고 국소 최소가 여러 개다. 좋은 국소 최소를 바란다.
   - 두 가지 전략: **느린 학습**(경사하강, 조기 종료)과 **규제**.
   - 경사하강: 기울기, 학습률 $\rho$, 갱신식.
   - 역전파: 단층 신경망의 기울기를 연쇄법칙으로 유도한다. 잔차가 은닉 단위와 입력으로 "책임"이 나뉘어 전달되는 것으로 해석한다. 다층은 같은 연쇄법칙의 반복이라고 말하고, 식은 단층만 쓴다.
   - 확률적 경사하강: 미니배치, 에폭 정의. MNIST 예: 훈련 48,000건, 배치 128이면 에폭당 약 375회 갱신.
   - **예시 1: 1차원 경사하강** (그림 10.17 방식). 비볼록 함수에서 시작점에 따라 국소 최소 또는 전역 최소로 간다. base R로 직접 구현한다.
   - **예시 2: 기울기 수치 검증.** 작은 단층 신경망에서 (10.29), (10.30)의 해석적 기울기와 유한 차분 기울기가 일치함을 base R로 보인다. 손으로 쓴 식이 맞는지 확인하는 용도다.
4. **규제와 조율 (10.7.2~10.7.4)**
   - 능선과 Lasso 벌점, 층별 $\lambda$, 출력층은 벌점을 주지 않는 관행.
   - 드롭아웃: 비율 $\phi$, 학습할 때마다 은닉 단위를 무작위로 제외하고 남은 단위의 가중치를 $1/(1-\phi)$배.
   - 조기 종료: 검증 목적함수가 오르기 시작하면 중단(ISLR은 약 30 에폭에서 오르기 시작한다고 서술).
   - 조율 항목 표: 은닉층 수와 층별 단위 수(현재 관점은 단위를 넉넉히 두고 규제로 과적합을 제어), 층별 $\lambda$와 $\phi$, 배치 크기, 에폭 수, 데이터 증강.
   - **예시: Hitters 단층 신경망** (아래 "Hitters 설계").
   - **예시(선택): MNIST 다층망** (아래 "MNIST").
5. **보간과 이중 하강 (10.8)**
   - 편향-분산에서는 훈련 자료를 보간하는 것을 피하라고 했다. 그러나 특정 조건에서는 보간하는 모형이 약간 덜 복잡한 모형보다 낫다.
   - 이중 하강의 정의: 보간 문턱 전까지 U자, 문턱 근처에서 폭증, 이후 다시 하강.
   - 편향-분산과 모순되지 않는다. 가로축이 기저 수일 뿐이어서, 보간하는 모형의 실제 유연성을 제대로 나타내지 못한다.
   - 조건: 신호 대 잡음비가 높을 때. 0 훈련 오차가 항상 최적은 아니다.
   - 규제와 조기 종료는 보간하지 않으므로 이중 하강을 보이지 않고, 적절한 $\lambda$면 더 좋은 결과를 낸다. SVM의 최소 노름 해와도 연결한다.
   - **예시: 이중 하강 재현** (아래 "이중 하강 설계").
6. **비교**
   - 표 1: 선형회귀 / Lasso / 단층 신경망 / 다층 신경망. 축: 모형 형태, 비선형과 상호작용, 모수 수, 해석 가능성, 적합 방법(닫힌 해, 볼록, 비볼록), 필요한 자료량.
   - 표 2: 다항 로지스틱 / LDA / 다층 신경망 (MNIST, Table 10.1 인용).
   - 표 3: 활성화 함수(시그모이드, ReLU): 식, 값의 범위, 계산 효율, 쓰임.
   - 표 4: 규제 방법(능선, Lasso, 드롭아웃, 조기 종료): 작동 방식, 조율 모수, 결과의 성질.
   - 표 5: 경사하강 / 확률적 경사하강: 한 번의 갱신에 쓰는 자료, 비용, 잡음.
   - 선택 기준: 해석이 중요하거나 자료가 작으면 선형모형이나 Lasso부터 시험한다. 단순한 모형이 비슷하게 맞으면 그쪽을 택한다는 원칙은 `dm-deep-learning`의 10.6 절로 연결한다.
7. **정리**: 핵심 식, 혼동 포인트(bias 용어, 비볼록, 이중 하강의 조건).

**핵심 식** (기호는 ISLR 표기를 따른다)

- 단층: $A_k=h_k(X)=g\!\left(w_{k0}+\sum_{j=1}^pw_{kj}X_j\right)$, $f(X)=\beta_0+\sum_{k=1}^K\beta_kA_k$ (10.1~10.3)
- 활성화: $g(z)=\frac{e^z}{1+e^z}=\frac{1}{1+e^{-z}}$ (10.4), $g(z)=(z)_+$ (10.5)
- 제곱오차 손실: $\sum_i(y_i-f(x_i))^2$ (10.9)
- 2층 활성화: $A^{(1)}_k=g\!\left(w^{(1)}_{k0}+\sum_jw^{(1)}_{kj}X_j\right)$ (10.10), $A^{(2)}_\ell=g\!\left(w^{(2)}_{\ell0}+\sum_{k=1}^{K_1}w^{(2)}_{\ell k}A^{(1)}_k\right)$ (10.11)
- 출력: $Z_m=\beta_{m0}+\sum_{\ell=1}^{K_2}\beta_{m\ell}A^{(2)}_\ell$ (10.12), $f_m(X)=\Pr(Y=m\mid X)=\frac{e^{Z_m}}{\sum_{\ell=0}^{9}e^{Z_\ell}}$ (10.13)
- 교차 엔트로피: $-\sum_{i=1}^n\sum_{m=0}^9y_{im}\log f_m(x_i)$ (10.14), $y_{im}$은 원-핫 지시변수
- 목적함수: $R(\theta)=\frac12\sum_i(y_i-f_\theta(x_i))^2=\sum_iR_i(\theta)$ (10.25). ½은 미분을 간단히 하려는 것이며 (10.9)에는 없다.
- 경사하강: $\theta^{m+1}\leftarrow\theta^m-\rho\nabla R(\theta^m)$ (10.27)
- 역전파(단층). $z_{ik}=w_{k0}+\sum_jw_{kj}x_{ij}$로 두면
  - $\frac{\partial R_i}{\partial\beta_k}=-(y_i-f_\theta(x_i))\,g(z_{ik})$ (10.29), $\frac{\partial R_i}{\partial\beta_0}=-(y_i-f_\theta(x_i))$
  - $\frac{\partial R_i}{\partial w_{kj}}=-(y_i-f_\theta(x_i))\,\beta_k\,g'(z_{ik})\,x_{ij}$ (10.30)
- 규제 목적함수: $R(\theta;\lambda)=-\sum_i\sum_my_{im}\log f_m(x_i)+\lambda\sum_j\theta_j^2$ (10.31). Lasso는 $\lambda\sum_j|\theta_j|$. 층마다 $\lambda$를 달리할 수 있고, ISLR의 MNIST 예에서는 $W_1,W_2$에만 벌점을 주고 $B$에는 주지 않았다.
- 드롭아웃: 은닉 단위를 확률 $\phi$로 제외, 남은 단위의 가중치에 $1/(1-\phi)$
- 모수 수: 층 $\ell$의 가중치 행렬 $(\text{입력 수}+1)\times(\text{출력 수})$

**Hitters 설계**

ISLR 10.9.1은 선형모형, Lasso, 신경망을 같은 분할에서 평균절대오차(MAE)로 비교한다. 설정은 `na.omit` 후 $n=263$, 테스트 1/3, 입력은 표준화한 `model.matrix(Salary ~ . - 1)`(열 20개), 신경망은 은닉 50개, ReLU, 드롭아웃 0.4, RMSprop, 1500 에폭, 배치 32다.

- **이 글의 모형은 ISLR과 다르다.** `nnet`은 시그모이드 은닉 단위, 선형 출력(`linout = TRUE`), 가중치 감쇠(`decay`), BFGS를 쓰고 ReLU, 드롭아웃, 미니배치가 없다. 따라서 ISLR이 보고한 MAE와 숫자를 비교하지 않는다. 글에 모형이 다르다고 밝히고, 같은 개념(은닉층, 규제)을 보여 주는 용도임을 적는다. ISLR의 정확한 모형은 12번 글에서 `torch`를 쓰는 경우에만 시도한다.
- **`MaxNWts`를 지정한다.** `size = 50`이면 가중치가 $50\times(20+1)+51=1{,}101$개로 `nnet` 기본 한도 1000을 넘어 "가중치의 개수가 너무 많습니다" 오류가 난다(계획 단계에서 R로 확인). `MaxNWts = 5000` 이상으로 지정한다.
- **비볼록성을 코드로 다룬다.** `nnet`은 초기값에 따라 결과가 달라진다. 초기값을 여러 개(예: 10개) 시도해 훈련 목적함수가 가장 낮은 것을 고르는 과정을 보인다.
- **전처리.** 입력은 훈련 자료의 평균과 표준편차로 표준화한다. 반응 `Salary`는 천 달러 단위라 규모가 크므로 필요하면 스케일을 조정하고 MAE는 원래 단위로 돌려 쓴다.
- **비교는 반복 분할로 한다.** 분할 하나(검증 약 88명)로 우열을 말하지 않는다. 같은 분할 50~100개에서 세 모형의 MAE를 구하고, 모형별 평균과 평균의 몬테카를로 SE, 분할별 차이(짝지은)의 평균과 SE를 표로 낸다. 차이가 SE의 2배 안이면 우열을 쓰지 않는다.
- 결과를 미리 정하지 않는다. ISLR 10.6은 이 자료에서 단순한 모형이 신경망과 비슷하게 맞을 수 있다고 논의한다. 실행 결과를 그대로 쓴다.
- 비교 대상: `lm`, `glmnet`(Lasso, 교차검증 `type.measure = "mae"`), `nnet`.
- `dm-deep-learning`의 10.6 절이 이 결과를 다시 인용할 수 있도록 같은 분할과 지표를 쓴다.

**이중 하강 설계**

계획 단계에서 R로 확인한 사항이다. 글에는 재실행한 값을 쓴다.

- 자료: $X\sim U[-5,5]$, $\epsilon\sim N(0,0.3^2)$, $Y=\sin X+\epsilon$, $n=20$. 신호 대 잡음비 $\mathrm{Var}(f(X))/\sigma^2$는 ISLR 기준 5.9.
- 기저: `splines::ns(x, df = d, intercept = TRUE)`. **절편 포함 열 수가 $d$**가 되게 해야 보간 문턱이 $d=20=n$에 온다. `ns`는 $d>n$이어도 동작하고, 매듭은 훈련 $x$의 분위수로 자동 계산된다. 최소 노름 해는 `MASS::ginv(X) %*% y`. 최소 노름은 기저에 따라 달라지므로 어느 기저인지 글에 적는다.
- 확인된 사실: $d\ge21$에서 열 수는 $d$지만 rank는 20에 머문다. 훈련 오차는 $d=20$ 이상에서 0이다.
- 테스트 오차 정의를 하나로 정한다. 확인은 참함수와의 거리 $\frac1{1000}\sum(f(x_t)-\hat f(x_t))^2$로 했다. 잡음을 포함한 테스트 오차로 쓰려면 $\sigma^2=0.09$를 더하고, 글에 어느 쪽인지 적는다.
- 확인된 시드 1의 테스트 오차(참함수 기준): $d=8$ 0.040, $15$ 0.230, $19$ 0.583, $20$ 0.551, $21$ 1.667, $25$ 1.819, $42$ 0.209, $80$ 0.481. $d=42$가 $d=20$보다 낮아 두 번째 하강이 보인다.
- **시드를 평균하면 안 된다.** 200개 시드의 평균 테스트 MSE는 꼬리가 두꺼워 쓸 수 없다. $d=21$에서 평균 2,639, 중앙값 4.1, 최댓값 445,559, 평균의 SE가 평균의 85%다. 따라서 다음으로 그린다.
  - 대표 시드 1개의 곡선(ISLR 그림과 같은 방식)
  - 200개 시드의 **중앙값과 사분위 범위**, 세로축은 **로그**
  - 평균 곡선은 그리지 않는다. 평균을 쓰지 않는 이유를 한 문장으로 적는다.
- 비교 곡선: 같은 기저에 **능선 회귀**(적절한 $\lambda$)를 적합한 곡선을 함께 그린다. ISLR의 서술대로 이중 하강이 없고 오차가 더 낮은지 실행해서 확인하고, 결과가 다르면 그대로 쓴다.
- 패널: 적합 곡선 4개($d=8, 20, 42, 80$)와 참함수, 훈련 점.

**MNIST (선택, 사용자 확인 필요)**

- `torch`, `luz`, `torchvision` 설치와 MNIST 내려받기가 필요하다. 설치 전에 사용자에게 내려받을 파일(libtorch, MNIST)과 용량을 말하고 허락을 받는다. 허락이 없거나 실패하면 코드를 `norun`으로 두고, 수치는 ISLR Table 10.1을 인용(출처 표시)한다.
- 실행한다면 ISLR 구조(은닉 256, 128, 소프트맥스 10)와 훈련 20% 검증, 배치 128을 따른다. 결과는 한 번의 훈련이므로 오차율의 이항 표준오차를 함께 적고 ISLR 값과의 차이를 우열로 해석하지 않는다.

**그림(SVG):** 단층 망 구조(입력, 은닉, 출력과 $A_k$), $z^2$ 손계산 도식, 역전파에서 잔차가 나뉘는 흐름, 다층 망(MNIST 모수 수 표기), 드롭아웃 전후. 코드 그림: 1차원 경사하강 경로, 기울기 검증, Hitters MAE 분포, 이중 하강 곡선.

**주의 (글의 `> 주의` 블록)**

- 이중 하강은 편향-분산 교환과 모순되지 않는다. 가로축이 보간하는 모형의 실제 유연성을 나타내지 못할 뿐이다(10.8).
- 이중 하강은 신호 대 잡음비가 높을 때 나타난다. 0 훈련 오차가 항상 최적은 아니며, 적절한 $\lambda$의 규제나 조기 종료는 보간하지 않고도 더 좋은 결과를 낸다. 이 방법들은 이중 하강을 보이지 않는다.
- 신경망의 "bias"(절편)는 편향-분산의 bias가 아니다.
- 비볼록이므로 같은 모형도 초기값에 따라 다른 해에 도달한다. 한 번의 적합으로 결론을 내리지 않는다.

**고칠 것(신규 글이므로 해당 없음), 확인할 것**

- (10.29), (10.30)의 부호와 ½ 계수를 기울기 수치 검증으로 확인한다.
- 모수 수 계산을 코드로 한 번 더 검산한다.

### 13. dm-deep-learning (신규) · A형 · ISLR 10.3~10.6

**목표 목차**

1. 개념
   - CNN: 합성곱 필터(손계산), 채널, 풀링, 구조, 데이터 증강, 사전학습 모형
   - 문서 분류: 단어 주머니, Lasso와 신경망
   - RNN: 은닉 상태 갱신, 가중치 공유, 임베딩, LSTM 개요
   - 시계열 예측: AR 자료 구조, RNN과의 관계
2. 비교: CNN/RNN/다층망 표, 단어 주머니와 시퀀스 모형, AR 모형과 RNN, **언제 딥러닝을 쓰는가(10.6)**. 10.6의 Hitters 논의는 `dm-neural-network`의 Hitters 비교(같은 분할, 같은 MAE)를 인용하고 서로 링크한다
3. 예시
   - 합성곱: 작은 이미지 행렬에 필터를 적용하는 base R 계산(실행 가능)
   - NYSE: 로그 거래량을 $L=5$ 지연 AR로 적합하고 ISLR의 RNN 결과와 비교(RNN은 `torch` 가능 시 실행)
   - IMDb: 단어 주머니 + Lasso (자료 내려받기 가능 시)
   - CIFAR 또는 MNIST CNN (`torch` 가능 시)

**핵심 식**

- 합성곱 계산: $\text{출력}_{ij}=\sum_{u,v}\text{필터}_{uv}\,\text{입력}_{i+u,j+v}$
- RNN: $A_{\ell k}=g(w_{k0}+\sum_jw_{kj}X_{\ell j}+\sum_sb_{ks}A_{\ell-1,s})$, $O_\ell=\beta_0+\sum_k\beta_kA_{\ell k}$
- 손실: $(Y-O_L)^2$
- AR: $\hat v_t=\hat\beta_0+\hat\beta_1v_{t-1}+\cdots+\hat\beta_Lv_{t-L}$

**그림(SVG):** 합성곱·풀링 단계, RNN을 펼친 그림과 은닉 상태의 흐름.

**실행 원칙:** 무거운 모형은 `norun` + ISLR 수치 인용을 허용하되 출처를 적는다. 합성곱 손계산과 AR 비교는 반드시 실제로 실행한다.

### 14. dm-survival (신규) · B형 · ISLR 11장

생명과학통계 생존분석(SAS, 생명표, 임상 예제)과 역할을 나눈다. 이 글은 ISLR 범위를 빠짐없이 다루고 통계적 학습 관점(벌점 Cox, 예측 성능)을 강조한다.

**목표 목차**

1. 생존시간, 중도절단, 독립 중도절단 가정
2. Kaplan-Meier 곡선
3. 로그순위 검정
4. 위험함수, 비례위험모형, 부분가능도
5. Cox 벌점: Ridge·Lasso와 예측 위험 집단
6. 추가 주제: 생존 AUC와 C-지수, 시간 척도, 시간의존 공변량, 비례위험 가정 점검, 생존나무
7. 비교: KM/로그순위/Cox/벌점 Cox, 로지스틱과 Cox, 데이터 마이닝과 생명과학통계 글의 역할
8. 예시와 사용: BrainCancer(KM, 로그순위, Cox), Publication(Cox, 벌점), 콜센터 모의 자료(시간대, 상담원 수, 콜센터 효과, ISLR 11.8.3 방식)

**핵심 식**

- $Y=\min(T,C)$, $\delta=I(T\le C)$
- $\hat S(d_k)=\prod_{j=1}^k\frac{r_j-q_j}{r_j}$
- $W=\frac{\sum_k(q_{1k}-\mu_k)}{\sqrt{\sum_k\mathrm{Var}(q_{1k})}}$, $\mu_k=\frac{r_{1k}}{r_k}q_k$, $\mathrm{Var}(q_{1k})=\frac{q_k(r_{1k}/r_k)(1-r_{1k}/r_k)(r_k-q_k)}{r_k-1}$
- $h(t)=\lim_{\Delta t\to0}\frac{P(t<T\le t+\Delta t\mid T>t)}{\Delta t}=\frac{f(t)}{S(t)}$
- $L=\prod_if(y_i)^{\delta_i}S(y_i)^{1-\delta_i}$
- $h(t\mid x_i)=h_0(t)\exp(\sum_jx_{ij}\beta_j)$
- $PL(\beta)=\prod_{i:\delta_i=1}\frac{\exp(\sum_jx_{ij}\beta_j)}{\sum_{i':y_{i'}\ge y_i}\exp(\sum_jx_{i'j}\beta_j)}$
- 벌점 부분가능도: $-\log PL(\beta)+\lambda P(\beta)$

**패키지:** `survival`, `glmnet(family = "cox")`.

**주의로 넣을 것:** 동률이 없으면 로그순위 검정과 단일 이진 변수 Cox의 점수 검정이 같다. 위험비는 시간에 따라 일정하다는 가정이 있으며, 곡선이 교차하면 의심한다.

### 15. dm-pca · B형 · ISLR 12.1~12.3

**목표 목차**

1. 비지도의 어려움
2. 주성분의 정의: 적재값, 점수, 최적화 문제
3. 고유값 분해와 SVD
4. 근사 해석: 저차원 근사
5. PVE, 스크리 그림, 표준화, 유일성, 개수, 다른 용도
6. **결측과 행렬 완성**: 문제 정의, 알고리즘 12.1, 추천 시스템
7. 비교: PCA/PCR/PLS/LDA/SOM(기존 표), 평균 대치와 행렬 완성
8. 예시: USArrests(기존), 행렬 완성(USArrests에 인위적 결측)

**핵심 식**

- $z_{i1}=\sum_j\phi_{j1}x_{ij}$, $\max\frac1n\sum_i(\sum_j\phi_{j1}x_{ij})^2$ s.t. $\sum\phi_{j1}^2=1$
- $x_{ij}\approx\sum_mz_{im}\phi_{jm}$
- $\mathrm{PVE}_m=\frac{\sum_iz_{im}^2}{\sum_j\sum_ix_{ij}^2}$
- $\min\sum_{(i,j)\in\mathcal O}(x_{ij}-\sum_ma_{im}b_{jm})^2$

**행렬 완성 예시:** `svd()`로 알고리즘 12.1을 직접 구현한다(ISLR 12.5.2와 같은 방식). 평균 대치와 비교하고, 참값과의 상관을 여러 시드로 낸다.

**고칠 것:** 표본분산의 $1/n$과 $1/(n-1)$ 표기를 정한다. ISLR 식은 $1/n$이고 `prcomp`는 $1/(n-1)$이다. 어디서 왜 다른지 적는다.

### 16. dm-clustering · A형 · ISLR 12.4 + 강의 SOM

**목표 목차**

1. 개념: 거리와 표준화, K-means(알고리즘 12.2), 계층적 군집(알고리즘 12.3, 덴드로그램 해석, 연결법, 거리), SOM(강의 예제 유지), 실무 쟁점
2. 비교: 기존 표 + 선택 기준 (중복 절 통합)
3. 예시: 동심원, USArrests, wines, **NCI60**(PCA 후 군집)

**핵심 식**

- $\min_{C_1..C_K}\sum_k\frac{1}{|C_k|}\sum_{i,i'\in C_k}\sum_j(x_{ij}-x_{i'j})^2$
- 항등식 $\frac{1}{|C_k|}\sum_{i,i'}\sum_j(x_{ij}-x_{i'j})^2=2\sum_i\sum_j(x_{ij}-\bar x_{kj})^2$
- 연결법 표: 완전, 단일, 평균, 중심
- SOM 갱신식(기존 유지)

**실무 쟁점(12.4.3)에 넣을 항목:** 표준화 여부, 거리와 연결법, K 개수, 덴드로그램 자르는 높이, 군집 유효성, 이상값 강건성, 부분 표본에서의 불안정성, 결과를 가설로 다루기.

**주의:** 덴드로그램에서 가로로 가까이 있는 것은 가깝다는 뜻이 아니다. 합쳐지는 **세로 높이**가 거리를 나타낸다.

### 18. dm-multiple-testing · A형 · ISLR 13장

현재 2,094자, 표시 수식 0개로 시리즈에서 가장 얇다. 전면 재작성한다.

**목표 목차**

1. 개념
   - 가설검정 복습: 4단계, 제1종·제2종 오류
   - 다중검정의 어려움: 동전 1,024명 예시, 탐색의 문제
   - FWER: 정의, $m$에 따른 증가
   - 본페로니, 홀름(알고리즘 13.1)
   - 특수한 경우: Tukey, Scheffé
   - FWER와 검정력의 교환
   - FDR: 직관, BH(알고리즘 13.2)
   - 재표집 p값(알고리즘 13.3), 재표집 FDR(알고리즘 13.4), 언제 유용한가
2. 비교: 방법 표 + 검정력 모의실험
3. 예시: Fund(운용사 평균 수익, `p.adjust`, `TukeyHSD`), Khan(유전자별 재표집 p값, FDR)

**핵심 식**

- $\mathrm{FWER}=P(V\ge1)$, $\mathrm{FWER}(\alpha)=1-(1-\alpha)^m$ (독립)
- 본페로니 $P(\cup A_j)\le\sum P(A_j)$
- 홀름 $L=\min\{j:p_{(j)}>\frac{\alpha}{m+1-j}\}$
- $\mathrm{FDR}=E(V/R)$
- BH $L=\max\{j:p_{(j)}<qj/m\}$
- $p=\frac{\sum_{b=1}^BI(|T^{*b}|\ge|T|)}{B}$
- 재표집 $\widehat{\mathrm{FDR}}(c)=\frac{\hat V}{R}$, $\hat V=\frac{\sum_b\sum_jI(|T_j^{*b}|\ge c)}{B}$

**비교 축:** 통제 대상 / 전제 / 쓸 수 있는 대비 / 보수성 / 대표 사용처

| 방법 | 통제 | 적합한 상황 |
|---|---|---|
| 본페로니 | FWER | $m$이 작고 가정을 줄이고 싶을 때 |
| 홀름 | FWER | 본페로니를 항상 대체 가능 |
| Tukey | FWER | ANOVA의 모든 평균 쌍 |
| Scheffé | FWER | 사후에 고른 임의의 대비 |
| BH | FDR | 대규모 탐색 |
| 재표집 | p값·FDR | 귀무분포 근사가 의심될 때 |

**고칠 것:** `:88`이 "같은 설정"이라고 쓰지만 단일 시뮬레이션은 t, 반복 시뮬레이션은 z다. 본페로니 검정력 이론값이 0.115와 0.316으로 달라진다. 하나로 통일하거나 설정 차이를 명시한다.

**유지:** 단일 시뮬레이션의 기각 수 결과는 R로 재현 확인된 값이다(128/42, 6/0, 52/1). 코드를 바꾸면 다시 확인한다.
