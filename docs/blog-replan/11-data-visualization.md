## 4. 실행 환경

- 가상환경 `~/venvs/dv2021` (Python 3.12, uv): matplotlib, seaborn, plotnine, plotly, kaleido, folium, pandas, scipy, opencv-python-headless, shapely.
- 강의 당시(2021) 버전과 달라진 문법은 현재 버전에 맞춘다: `np.mean` 대신 `'mean'` 문자열 집계, `groupby(...).mean()`의 `numeric_only`, `plt.style`의 `seaborn-v0_8-*` 이름, plotnine의 `linewidth`.
- 이미지 예제는 저작권 문제가 없는 matplotlib 내장 표본 사진(Grace Hopper, 퍼블릭 도메인)을 쓴다.
- 그림은 Noto Sans KR, 위·오른쪽 축선 없음, 옅은 격자로 통일한다. 실행 스크립트는 저장소에 넣지 않는다.

## 5. 작업 결과 (2026-11-13)

- 12편 모두 `src/content/posts/data-visualization/dv-NN-*`에 작성, `draft: false`. 12편 slug는 `dv-12-folium-map`.
- 인터랙티브 그림은 `public/charts/dv/` (dv01 1개, dv11 7개, dv12 9개).
- 12편 지도는 OpenStreetMap 타일을 쓴다. CartoDB 타일은 미리보기에서 "API KEY REQUIRED"로 거부되었다. GeoJSON은 shapely로 단순화(시도 7.5MB → 111KB, 시군구 18MB → 547KB)해서 넣었다.
- 시군구 인구 표는 이름이 겹치고(중구 6곳 등) 표기가 달라 이름으로 연결하면 틀린다. 12편은 이름이 유일한 전라북도만 그리고, 이 함정을 본문에서 설명한다.
- 지진 자료의 날짜 3건이 ISO 형식이라 `split('/')`로 연도를 뽑으면 그룹이 55개가 된다. `to_datetime(format='mixed')`로 처리.
