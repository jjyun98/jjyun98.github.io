**목표:** 2판 범위를 함수 사전이 아닌 "무엇을 언제 쓰는가" 중심으로 복습할 수 있게 한다.

**변화:** 10편 → 17편(신규 7편, D4 결정에 따름). 순서를 책 순서로 바꾼다. 분석 시리즈보다 우선순위가 낮다.

**R4DS에서의 틀:** 수식 대신 함수의 역할을 쓴다.

```markdown
## 1. 개념      이 도구가 푸는 문제, 함수 지도
## 2. 비교      비슷한 함수의 차이와 선택
## 3. 예시와 사용      자료 → 코드 → 출력 → 해석
## 자주 하는 실수   이 시리즈만 유지
## 요약
## 참고자료
```

이미 대부분 글이 이 구조에 가깝다. **기존 글은 구조 대이동 없이 비교 절을 넣고 순서를 맞추는 수준으로 고친다.**

## 신규 글

### r4ds-logical-numbers (책 12, 13장)

**개념:** 논리 연산, `%in%`, 결측과 논리, `any`/`all`, `if_else`, `case_when`, 수 변환, `count`, 산술, 반올림, 구간화, 누적, 순위, 오프셋, 요약.

**비교:** `==`와 `near`, `&`와 `&&`, `if_else`와 `case_when`, `round`/`floor`/`ceiling`, `min_rank`/`row_number`/`dense_rank`, `lag`/`lead`.

**예시:** nycflights13 지연 비율, 지연의 전후 관계.

### r4ds-datetime (책 17장)

**개념:** date, datetime, 파싱 `ymd`, 구성요소 추출, 반올림, 시간 범위(duration, period, interval), 시간대.

**비교 표:** duration, period, interval의 차이(일광절약시간 예). `floor_date`와 `round_date`.

**예시:** flights의 시간대별 지연. **연결:** 시계열 시리즈.

### r4ds-external-data (책 20, 21, 22장)

**개념:** `readxl`, `googlesheets4`(`norun`), DBI와 dbplyr, duckdb, arrow, Parquet.

**비교 표:** CSV, Excel, DB, Parquet(속도, 크기, 언제). dplyr 코드와 SQL 번역(`show_query`).

**예시:** duckdb 메모리 DB, seattle 대신 작은 자료로 Parquet 왕복.

**연결:** `air-gapped-analysis-environment`.

### r4ds-hierarchical-web (책 23, 24장)

**개념:** 리스트 열, `unnest_longer`, `unnest_wider`, JSON, `rvest` 선택자, 스크래핑 윤리.

**비교:** `unnest_longer`와 `unnest_wider`, CSS 선택자 표, API와 스크래핑.

**예시:** `repurrrsive` 자료, 정적 HTML 문자열을 파싱(외부 사이트 호출 없음).

### r4ds-functions (책 25장)

**개념:** 벡터 함수, 데이터프레임 함수, 그래프 함수, 임보크(`{{ }}`), 스타일.

**비교:** 세 종류 함수 표, 데이터 마스킹과 tidy-select, `{{ }}`와 `pick`.

**예시:** 요약 함수, 히스토그램 함수.

### r4ds-base-r (책 27장)

**개념:** `[`, `[[`, `$`, `apply` 계열, `for`, base 그래픽.

**비교 표:** base와 dplyr 대응, `[`와 `[[`, `sapply`와 `vapply`. **연결:** 폐쇄망에서 Base R만 쓰는 `air-gapped-analysis-environment`.

### r4ds-quarto (책 28, 29장)

**개념:** 문서 구조, 청크 옵션, 인라인 코드, 표와 그림, 출력 형식.

**비교:** 청크 옵션 표, HTML·PDF·Revealjs, R Markdown과 Quarto.

**예시:** 짧은 분석 보고서 소스(`norun`). `quarto`가 설치되어 있지 않을 수 있으므로 렌더 결과는 실행했을 때만 넣는다.
