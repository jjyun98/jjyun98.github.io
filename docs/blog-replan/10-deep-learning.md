# 10. 딥러닝 시리즈 설계

작성일 2026-11-13, 개정 2026-11-14. 원자료: 최규빈, 「딥러닝」 강의노트 (2022), <https://guebin.github.io/DL2022/>

**원칙 (2026-11-14 사용자 요청):** 강의를 회차 순으로 옮기지 않는다. 블로그의 다른 시리즈(데이터 마이닝, 선형대수, 확률과정론)처럼 개념 중심으로 쓴다.

- 제목은 `딥러닝 - <개념>`. 첫 문단에 개념의 정의를 짧게.
- 정의·식 → 비교표 → 예제 → 요약. 강의 예제는 "강의 예제"로 한 곳에만 표시하고, 강의를 서술하지 않는다("강의는 ~라고 한다" 금지).
- 통계·선형대수 시리즈와 교차 링크(GLM, 스플라인, 릿지, SVD, 마코프체인, ARMA 등).
- 다른 시리즈보다 유도 단계와 코드 설명은 조금 더 풍부하게. 한 편 200~300줄.
- 실험은 직접 돌린 값만 적는다. 긴 실험은 먼저 한 배치 시간을 잰다.
