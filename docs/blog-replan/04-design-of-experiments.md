## 글별 계획

### doe-01-basics · B형 · c1, c2.1

**목표 목차:** 표본분포 → 한 모집단 → 두 독립 모집단 → 대응 → 가정 검토 → 용어 → 기본 원리(반복, 랜덤화, 블록화, 직교화, 교락) → 실험 순서 → 비교 → 시리즈 표

**핵심 식:** $\bar X$, $t=\frac{\bar X-\mu}{S/\sqrt n}$, $\chi^2$, $F$, 합동분산 $S_p^2$, Welch 자유도, 대응 $t=\frac{\bar d}{s_d/\sqrt n}$.

**비교 축:** 독립과 대응, 합동과 Welch, 모수인자와 변량인자, 실험연구와 관찰연구.

**그림(현재 0장)**

- SVG: 랜덤화, 반복, 블록의 역할
- R: 대응 자료의 차이 분포, QQ 플롯

**고칠 것:** 합동 t와 Welch 선택 권고를 생명과학통계 `mean-comparison`과 일치시킨다. 사전 등분산 검정으로 고르는 2단계 절차를 권하지 않는다.

### doe-02-one-way · B형 · c2

**목표 목차:** 모형 → 변동 분해 → F 원리 → 가정 검토 → 수준별 추론 → 다중비교 → 대비 → 불균형 → 비모수 → 변량모형 → 비교

**핵심 식**

- $y_{ij}=\mu+a_i+e_{ij}$, $\sum a_i=0$
- $SS_T=SS_A+SS_E$, $F=MS_A/MS_E$
- $E(MS_A)=\sigma_E^2+rQ(A)$
- 수준 평균 구간, 대비 $L=\sum c_i\mu_i$
- 변량모형: $E(MS_A)=\sigma_E^2+r\sigma_A^2$, $\hat\sigma_A^2=(MS_A-MS_E)/r$
- $H=\frac{12}{N(N+1)}\sum\frac{R_i^2}{n_i}-3(N+1)$

**비교 표**

| 방법 | 통제 대상 | 적합한 경우 |
|---|---|---|
| LSD | 비교당 오류 | 사전 계획, 수가 적을 때 |
| 본페로니 | FWER | 대비 수가 적을 때 |
| Tukey | FWER | 모든 쌍 |
| Duncan | 단계별, 비교적 느슨 | 교재 범위 확인 후 |
| Scheffé | FWER | 임의의 사후 대비 |
| Dunnett | FWER | 대조군과 비교 |

교재에 없는 방법은 "교재 밖"으로 표시한다. 모수모형과 변량모형, ANOVA와 Kruskal-Wallis도 비교한다.

**연결:** 다중비교 이론은 `dm-multiple-testing`, 실제 임상 사례는 `biostat-mean-comparison`.

### doe-03-two-way · B형 · c3

**목표 목차:** 반복 없는 이원배치 → 최적조건 → Tukey 비가법성 → 교호작용 이해 → 반복 있는 이원배치 → EMS(모수모형) → 풀링 → 비교

**핵심 식:** 모형 2개, 제곱합 분해, Tukey 비가법 제곱합, 최적조건 추정과 구간, Satterthwaite 또는 유효반복수.

**비교 축:** 반복 없음/있음(추정 가능한 것, 오차), 교호작용 유의 여부에 따른 평균 비교 방법, 풀링 전후.

**그림:** 교호작용 도표 패턴 SVG(없음, 순서형, 교차형).

**고칠 것:** 풀링 기준(F 값이 작을 때)을 교재대로 쓰고, 사전 검정에 기반한 풀링의 위험도 적는다.

### doe-04-multi-way-ems · B형 · c4, `ems.txt` · **WP-1 우선 수정**

#### 규칙 충돌 해결 방침

이 글의 가장 큰 문제다. 두 출처의 규칙이 서로 다르다.

- **교재(c4 법칙 1~5, 글 `:20~25`, `:175~177`):** 비제약 모형. 교재는 교호작용에 합 0 제약을 두지 않으며 SAS, SPSS 기본값과 같다.
- **강의 노트(`ems.txt`, 글 `:50~64`):** 제약 모형. "주어진 효과를 뺀 나머지가 전부 랜덤"인 교호작용만 포함한다.

글은 이 차이를 말하지 않고 섞어 쓴다. 어느 쪽이 틀린 것이 아니라 전제가 다르므로 **교재 규칙을 본문 기준으로 하고, 강의의 글자표기 규칙을 제약 모형으로 소개해 비교**한다.

**비교 표 (반드시 넣는다): $A$ 변량, $B$, $C$ 모수, 반복 있음**

| 효과 | 비제약 (교재, SAS, SPSS) | 제약 (강의 글자표기) | 분모가 달라지는가 |
|---|---|---|---|
| $A$ | $E+ABC+AB+AC+A$ | $E+A$ | **달라짐**: 근사 F 대 $E$ |
| $B$ | $E+ABC+AB+B$ | $E+AB+B$ | $AB$로 같음 |
| $C$ | $E+ABC+AC+C$ | $E+AC+C$ | $AC$로 같음 |
| $AB$ | $E+ABC+AB$ | $E+AB$ | **달라짐**: $ABC$ 대 $E$ |
| $AC$ | $E+ABC+AC$ | $E+AC$ | **달라짐**: $ABC$ 대 $E$ |
| $BC$ | $E+ABC+BC$ | $E+ABC+BC$ | $ABC$로 같음 |
| $ABC$ | $E+ABC$ | $E+ABC$ | $E$로 같음 |

위 표는 교재 법칙(c4)과 강의 규칙을 적용해 계산한 결과이며 계획 단계에서 확인했다. 예를 들어 $AB$의 제약 모형 EMS에 $ABC$가 빠지는 것은 $AB$를 뺀 나머지 인자 $C$가 모수이기 때문이다.

**핵심 메시지:** 이원배치 혼합모형($A$ 모수, $B$ 변량)에서 비제약은 $E(MS_B)=\sigma_E^2+r\sigma_{AB}^2+lr\sigma_B^2$, 제약은 $\sigma_E^2+lr\sigma_B^2$이다. 배터리 예제($C$ 변량)의 근사 F는 비제약 기준이므로 그대로 둔다. 제약 기준이면 $E(MS_C)=E+C$가 되어 분모가 $E$가 된다는 점을 함께 적는다.

**목표 목차**

1. 분산분석의 원리: 세 모형의 EMS 표
2. EMS 법칙(교재 법칙 1~6): 표 만들기, 법칙 5의 뜻
3. 자유도와 제곱합의 계산법칙(법칙 8, 9)
4. **제약 모형과 비제약 모형의 비교** (위 표, 어떤 소프트웨어가 어느 쪽인가)
5. 삼원배치 모수모형: 분석, 최적조건
6. 혼합모형과 근사 F, Satterthwaite
7. 분산성분 추정
8. 4인자 이상의 일반화

**핵심 식:** EMS 일반형, $\hat\sigma^2$ 추정, 근사 F, Satterthwaite $\nu$.

**그림(현재 0장)**

- SVG: EMS 표를 채우는 절차
- SVG: 제약과 비제약의 차이(교호작용 합 0 제약 유무)
- R: 삼원배치 주효과, 교호작용 도표

**R 확인:** 비제약 EMS를 `lm` 기반 소량 모의실험으로 확인한다. $MS$ 평균이 표의 이론값과 맞는지 몬테카를로 표준오차와 함께 보인다.

### doe-06-two-level-factorial · B형 · c6.1~6.2

**목표 목차:** 요인실험 개념 → 표기 → 대비, 효과 → 부호표 → 회귀와의 관계 → Yates → 효과 판정(Daniel, Lenth, 풀링) → 중심점과 곡률 → 비교 → 예제

**핵심 식:** $A=\frac{1}{2^{n-1}r}[\text{대비}]$, $SS=\frac{\text{대비}^2}{2^nr}$, 회귀계수 = 효과/2, $s_0$, $PSE$, 곡률 $SS=\frac{n_Fn_C(\bar y_F-\bar y_C)^2}{n_F+n_C}$.

**비교 축:** Daniel/Lenth/풀링(객관성, 전제), 요인실험과 한 번에 한 인자 실험.

**유지:** 한 번에 한 인자 모의실험. 몬테카를로 표준오차 확인.

### doe-07-confounding-fractional · A형 · c6.3~6.5

**목표 목차**

1. 개념: 교락과 합동식 블록, 단독·2중·부분 교락, 일부실시와 별명, 분해능, 직교배열표와 선점도
2. 비교: 기존 표 + 교락과 일부실시의 목적 차이, 분해능 표
3. 예시: $2^4$ 2중교락, 별명 예제, 직교배열 배치, 4수준 인자 배치(연습 6.7, 6.8 개념)

**그림(현재 0장)**

- SVG: $2^3$ 큐브와 블록 나누기
- SVG: 일부실시 반쪽 선택
- SVG: 선점도

**유지:** 별명이 실제로 무엇을 섞는지 보여주는 예제. R로 재현 확인된 값이다.

### doe-10-rsm-mixture · B형 · c9

**목표 목차:** RSM 흐름 → 1차 모형, 최대경사 → 2차 모형, 정상점, 정준분석 → CCD, Box-Behnken 비교 → 여러 반응 → 혼합물 제약, 실험점, 정준 다항식 → 비교

**핵심 식:** $\hat y=b_0+x^Tb+x^TBx$, $x_s=-\frac12B^{-1}b$, 회전성 $\alpha=F^{1/4}$, Scheffé 혼합 모형.

**비교 축:** 일반 요인실험과 혼합물, CCD와 Box-Behnken, 정상점 유형(최대, 최소, 안장).
